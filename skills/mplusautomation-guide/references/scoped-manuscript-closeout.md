# Close a manuscript from existing evidence

Use this route when the author has explicitly chosen a narrower manuscript
after a reproducibility or numerical audit. It does not authorize abandoning
the original research objective without that decision.

## Resume the actual artifact, not the oldest handoff

Read the latest requested session, then inventory the actual delivery root.
Compare document hashes, numerical receipts, rendered pages, review receipts
and publication receipts. A stale HANDOFF can lag a fully generated candidate;
restart at the first missing gate. Do not rerun Mplus to repair a Word label,
citation, stale progress flag or missing release receipt. Preserve originals
and isolate candidate edits outside the data and synchronized source trees.

Keep four states distinct: historical reproduction, corrected-data estimation,
scientific adoption and manuscript delivery. A model can reproduce a historical
table without supporting its original interpretation. Conversely, withdrawing
a conclusion can close an editorial issue without completing that hypothesis.

## Stop numerical work honestly

- Preserve frozen tolerance rules and their original decision. Report both the
  numerical difference and its substantive scale; a project tolerance is not a
  universal statistical theorem. A small failed start check does not prove
  theoretical nonidentification or justify an unlimited retry loop.
- Iteration counts, acceleration steps and rounded likelihood changes are
  diagnostic observations. They do not prove the final gradient or the cause
  of differing terminations. Keep a hypothesis separate from demonstrated cause.
- A legal single-imputation fit is not a complete MI family. Do not combine
  different starts or fixed-residual settings as if they were imputations.
  Low FMI in a different, noninteraction model cannot predict unrun interaction
  members, convergence, intervals or significance.
- Fixing a conditional growth residual to zero is a structural restriction,
  not proof of zero population variation. Similar interaction coefficients do
  not establish stable conditional slopes or uncertainty across constraints.
- Record optional final probes separately. A zero-new-estimation authorization
  means zero engine calls, including synthetic calls and automatic retries.
  Leave valuable but unperformed analyses in an explicit untested register.

## Retain a readable research paper

Keep the adopted results and uncertainty central. Move extensive failed-model
ledgers, empty result tables and runtime history to a labelled audit supplement.
Retain original hypotheses and historical drafts; disclose the retrospective
scope change. Do not replace “untested” with “no effect”, or overlapping-model
results with “independent replication”. Preserve exact parameter semantics,
including direct paths that affect the meaning of a latent-intercept path.

Reuse the existing table/cell validator and build a numeric claim-to-source map
for the current main text. Preserve editable citation fields and footnotes across
document moves. Distinguish complex-field counts from Word's aggregate Fields
count, which may include hyperlinks. Export same-version PDFs through the
validated platform runtime and actually inspect rendered pages.

## Review and release are version-bound

Follow the author's requested PDF-only NLM review contract. Save original
responses, source IDs, source hashes, tool return codes and issue dispositions.
An answer that says “no issues” but returns empty `sources_used` and citations
does not pass the source-bound gate. Manually written `[filename.pdf]` text is
not a native source citation. Preserve the invalid response, check auth separately,
and ask for genuine source-grounded review; do not fabricate metadata.

Freeze the final PDF pair before the final review sequence. A later Word/PDF
change invalidates review acceptance for the older hash. A5 requires two
consecutive no-new-issue rounds with fresh uploads OR three consecutive same
location/type findings with evidence-based supervisor adjudication. NLM opinions
cannot replace local arithmetic, model provenance or visual inspection.

Adjudicate the proposed fix as well as the reported defect. In the Windows
closeout, NLM correctly found a missing Raudenbush/Chan (1992) reference but
proposed a different title and incorrect bibliographic details. The publisher
record identified *Growth Curve Analysis in Accelerated Longitudinal Designs*,
DOI `10.1177/0022427892029004001`. Preserve the raw suggestion and record the
verified replacement. Do not copy an AI-supplied reference without checking it.
For a minimal citation correction, preserve Word's editable citation
instructions and footnotes, verify table XML is unchanged, and export/review
the revised PDF pair. Earlier-hash reviews remain historical evidence.

Package an explicit aggregate-only whitelist. Retain all dispositions, exact
file hashes and runnable saved-output validators; exclude participant records,
raw DAT, MI objects, per-person scores, credentials and literature fulltexts.
For a 25 MB limit use the strict 25,000,000-byte threshold. Validate ZIP CRC,
payload uniqueness and the manifest before publication. Download from an
immutable commit anonymously, then repeat package and numerical verification.
Keep the post-download proof separate from the immutable payload it verifies.

Completion is scoped: evidence accepted, manuscript checked, review resolved,
release independently downloaded. It does not mean every original hypothesis
was estimated or supported. Stop routine model work at the agreed endpoint.

## Portability boundary

The PP-LGCM case exercised Windows native Word, Python and CLI tools under a
WSL-controlled session. Keep native Windows paths at executable boundaries and
UTF-8 in captured output. Inspect only the requesting host's NotebookLM proxy;
the Windows rule is `DOMAIN-SUFFIX,notebooklm.google.com,链式代理-Gemini`.
This experience does not establish licensed Mplus or Word automation on macOS.
An installed configuration can name a stale controller pipe while the live
Clash production core uses another one. Inspect the live local controller
read-only; do not rewrite the proxy or launch repeated login merely because a
network request failed. A successful cookie-free HTTPS probe proves egress,
not authenticated notebook access or a successful source-grounded review.
Provider-specific collaboration adapters must pass their actual client's
identity/input gates; a Codex pane is not a Claude callback. Preserve a rejected
dispatch and use an already authorized solo route without disabling guards.

## Delegate bounded review without duplicating computation

An existing visible executor is useful for an independent artifact/code audit
while the supervisor serializes NLM source changes and owns publication. Assign
an explicit read set, one report path, permitted writes, exclusions and a stop
condition. Do not run duplicate NLM queries, statistical engines or full test
suites in both panes merely to demonstrate activity.

Pane title, readiness and task completion are different observations. In the
Windows/WSL case, the actual Codex process ancestry and session identity proved
readiness; a separate input delivery and executor tool activity proved that the
audit started. The formal collaboration preflight rejected the Codex footer as
occupied input. Preserve that failure and do not label a directly authorized
ordinary audit as a validated V2 round or consensus. Do not disable global hooks
or clear unknown user input to make an adapter pass.

Write the report before notifying the supervisor. Detect supported bridge
commands once: the observed tmux-bridge 2.0 had no `notify` command. A scoped tmux
status message plus a task-specific wait-for signal can announce a report
without typing into a busy supervisor; neither substitutes for a formal callback
when the chosen protocol requires one. The supervisor must read the report,
record its verdict and check actual artifacts before claiming participation or
acceptance. Preserve a stable report path as recovery evidence if a notification
is lost. Reuse the measured client/model and do not start replacement sessions
solely because a title or historical registry suggests another executor.
