# Chapter 7 acceptance layers

The configurable entry, automatic classification-logit binding and model-object
figure adapters have independent synthetic tests. Generation uses
`mplusModeler(run=0)` and explicitly intercepts engine calls. This establishes
input compilation and rejection behavior, not native Mplus acceptance.

`scripts/ch7_native_fixture_20261111.R` generates a reproducible synthetic CSV
and configuration for continuous LPA, binary LCA, mixed measurement, invariant
four-wave LTA Step-1 and MS-LTA. `SYN_LTA4_MI_STEP1` explicitly uses
`transitions=FALSE`, matching the chapter's measurement-only Step-1 structure.
Its consumers and the MS-LTA model use `transitions=TRUE`. Transfer the actual generated bytes when using
another host; matching a random seed alone does not prove data identity.
The fresh Step-3 LTA and MS-LTA members must consume that execution's Step-1
output and its declared savedata through the automatic chain. Keep fixture
generation and fresh-chain receipts separate.

Native acceptance is **pending**. A future accepted receipt must record the
authorized dedicated Windows RStudio/ClaudeR identity, actual MplusAutomation
call, Mplus process and version, immutable input/output hashes, original attempt
costs, syntax acceptance, normal termination, warnings and parser status. A
standalone Rscript or direct executable invocation does not replace this route.
No native model was started to produce the offline test evidence in this change.

Historical validation uses the frozen original model with DATA/SAVEDATA path
substitutions only. It must compare fresh output with the accepted private
baseline at printed precision and preserve original diagnostics. This is
separate from a new real-data source swap. The historical MI_4W_FREE timeout
remains final and is not reopened by this work.

The existing transition-flow and quadratic-curve functions are reused. The new
adapter preserves explicit class semantics, conditional probability meanings,
log scales and complete covariance. Private historical figure comparisons do
not enter the public repository, and do not establish manuscript adoption or
new Mplus estimation.
