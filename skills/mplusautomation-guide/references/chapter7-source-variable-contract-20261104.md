# 第七章换源与换变量合同

用于把已有 LPA/LTA/MS-LTA 分析迁移到另一数据源或变量字典。先建立显式
映射和预期模型清单，再生成输入。本文定义审阅与验收合同；可执行配置见
[统一换源入口](chapter7-source-entry-20261111.md)。该入口支持连续量与0/1二分类、
各波同K；不推断任意变量变换或全部模型规格。

## 1. 先固定迁移模式

`historical_replay` 要求冻结原数据值、样本、变量类型、波次、分类误差、
starts、seed、估计器与约束。仅迁移文件路径时，记录允许改变的路径字段
和前后 INP SHA，其他语法逐项核对。未显式写 seed 的旧输入保留该事实，
并记录 Mplus 版本，不补造种子一致性。

`new_source` 或 `new_variables` 是新的模型输入：可借用结构与生成方式，
但必须重新生产 panel、标准化指标、类别测量、CPROB 和 Step-3 校正参数。
不以行数相同、列名相同或旧 `.out` 可解析宣称复现。两种模式分别使用输出
根与验收基线。

## 2. 显式配置字段

下列是项目配置应具备的字段要求；实际 API 字段和示例见统一入口文档。

| 配置部分 | 必填内容 | 生成前验收 |
|---|---|---|
| source | 路径、SHA256、格式、编码、缺失码、ID、行粒度 | 文件身份、ID 唯一性、样本规则和排序稳定 |
| waves | 有序波次、实际年份、模型潜变量名 | 四波与两期分开；真实间隔不靠后缀猜测 |
| indicators | 每波源列→模型名、continuous/categorical、尺度与取值 | 类型、阈值/类别编码和跨波可比性 |
| transformations | 标准化基准、截尾、派生表达式、缺失传播和执行顺序 | 检查源值到目标值；不套用另一分支的标准化结果 |
| classes | 枚举范围、单期选择、纵向选择、类别命名依据 | 分别保存统计选择与纵向可比性决策 |
| model | 生成入口、估计器、starts/LRTSTARTS、seed、PROCESSORS、测量约束 | 与预期 INP 差异逐条可解释；资源调整另记 |
| step3 | Step-1 OUT/CPROB SHA、ID 列、误分类矩阵、固定阈值、参考类 | 列宽、行键、数值投影与生产脚本一致 |
| ms_lta | G 定义、mover/stayer 组、转移约束和概率条件集合 | 精确约束与有限 logit 近似分别声明 |
| output | 隔离根、model_id、预期文件清单、图表口径、比较基线 | 无历史输出覆盖；每个消费者绑定具体生产者 |

第七章的混合测量例子要求逐波映射四个连续量 `closz/esupz/isupz/opp5z`
以及两个分类量 `edwc/idwc`。分类量来自 `DEFINE`：先置 0，再按
`edw < esup*1` 或 `idw < isup*1` 置 1。因此新源的映射还要包含
`edw/esup/idw/isup` 四个派生依赖，不能只更名最终六个模型变量。此处记录
历史表达式；它是否适合新量表必须重新决定，不能把表达式中的 1 当成自动
适用的通用阈值。

## 3. 生成、运行、读取

1. 保存源快照、变量映射、原生成区块和模型清单的 SHA。读取旧脚本时只取
   所需区块，不执行安装、删除或写回原研究目录的动作。
2. 先生成一个最小代表输入，核 `NAMES` 的 DAT 列序、`USEVARIABLES`、
   `CATEGORICAL`、`DEFINE`、`CLASSES` 与 `MODEL`。确认派生变量的类型、
   缺失规则和生成位置，再展开全量清单。
3. 新数据/新规格先用合成数据通过真实引擎检查。历史复现则复用已核原
   INP/DAT，记录路径替换白名单；不要为了通过 smoke 修改历史研究规格。
4. 在获准的计算窗口按依赖提交一次，保留实际进程、版本、开始/结束、输入
   和输出 SHA。以原 job/attempt 接回未知状态，不因等待超时重复提交。
5. 读取每个输出与 savedata，区分模型结束、估计诊断、解析成功。类别比例
   保留三种口径，转移表保留条件集合，再执行类别语义映射和逐单元比较。
6. 重出表图并保存来源绑定。若声明本次端到端新鲜复现，Step-3 必须绑定
   本次 Step-1 的误分类信息。已保存的历史生产链可经生产脚本、参数、行键、
   数值投影与 SHA 的只读审计闭合；与本次新鲜链和归档 Step-3 重放分别报告。

## 4. 验收层次

- `TRANSFER_VERIFIED`：明确文件集合逐件字节身份一致。
- `ARCHIVED_READBACK_ONLY`：读取并重绘已存在输出，没有新引擎估计。
- `FRESH_REPLAY_COMPARED`：新的引擎回执及对应数值比较已完成；另列诊断。
- `LINEAGE_CLOSED`：源 panel 到 Step-1、分类误差和 Step-3 的生产链已核。
- `MANUSCRIPT_ACCEPTED`：结果、类别标签、图表和正文经项目明确采纳。

这些是需要分别记录的证据层次，不保证线性自动升级。保留 `NOT_RUN`、
`MISMATCH`、`WITH_DIAGNOSTIC` 和未闭合项；历史 SE/导数失败的忠实复现
不等于该模型推断已可采用。详细家族边界见
[LPA/LCA](lpa-lca-workflow.md)、[MS-LTA](ms-lta-workflow.md)与
[第七章复现映射](chapter7-replay-map.md)。
