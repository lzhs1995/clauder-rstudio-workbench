# LTA workflow

LTA 是把多个时间点的潜在类别连接起来的纵向模型。它同时包含每期的测量部分、初始类别比例和相邻时间点的转移概率。第七章的 LTA 主线是“单期 LPA 识别 → 测量不变性 → 转移概率 → 描述性图表 → 影响因素策略选择”。

## 1. 建模顺序

### Step 0：单期 LPA 基线

每个时间点先完成类别数枚举和类别命名。类别编号必须在时间点之间通过条件均值/概率对齐。

### Step 1：测量不变性

依次比较：

- 非不变模型：每期条件均值/概率自由估计；
- 测量不变模型：跨期约束相同的测量参数；
- 必要时使用部分不变性，并明确释放哪些参数。

不能只看拟合差异。还要检查条件概率/均值图是否保持相同的类别形状、类别是否仍然可命名，以及约束是否造成异常类别。

### Step 2：转移概率

在确认测量结构后估计 `c2 ON c1; c3 ON c2;` 等相邻转移。报告每个起点类别到终点类别的概率矩阵、置信区间和类别基数。LTA 的一阶 Markov 假设必须在方法中明确：当前期状态由相邻前一期状态预测。

### Step 3：辅助变量或协变量

Vermunt 三步法、BCH 和一步法必须区分用途。三步法用于固定测量结构并减少辅助变量对类别测量的反向影响；BCH 更适合某些 distal outcome。具体选择取决于模型是普通 LTA、multiple-group LTA、MS-LTA 还是含 distal outcome 的模型。

第七章曾计划在 Mplus 中直接估计转移路径的直接/调节效应，但稀疏转移单元造成标准误膨胀、收敛失败和交互项编码复杂。最终把描述性 LTA 与机制回归分开：Mplus 负责类别/转移描述，R 负责导出 most-likely class 后的二元 logistic 回归。

## 2. MplusAutomation 批量模式

模板应把以下内容参数化：时间点、类别数、测量约束、随机起点、seed、savedata 文件名和输出目录。批量执行必须使用独立目录，禁止让不同规格共享 `.out` 或 savedata。

每个模型 receipt 至少记录：

- 输入 `.inp` 哈希；
- 数据 `.dat` 哈希和列数；
- Mplus 版本；
- 收敛状态、warning 和 TECH 输出；
- savedata 行数、列名和 CPROB 列数；
- `readModels()` 解析状态。
