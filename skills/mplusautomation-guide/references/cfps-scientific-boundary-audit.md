# CFPS 科学边界审计

技术回读、历史复原和科学采用必须分层记录。Windows 复盘时，将 156 个历史/当前版本差异、25 个 LRT 候选、MI v3 和 rank/derived score sources 放到同一个只读边界报告中，但不能用一个层级的通过替代另一个层级。

## 版本差异

只有在历史显示值、运行时输出哈希和脚本/模型身份都一致时，才能把单元格标成历史显示技术闭合。当前数据差异要进入敏感性或限制。对于本任务明确的 20260214 初稿复现目标，156 个已匹配单元格可由 `cfps_historical_version_adoption_20261004` 冻结为历史显示版本；这关闭历史复现版本选择，不等于修正数据的 scientific release。Table 4.2 的 16 个 AIC/BIC 舍入格另按 `cfps-rounding-contract.md` 固定 R `round()` 的显示规则。

## LRT

LRT p 值发布前必须同时保存精确的 null/alternative 输出对、完整嵌套语句、相同估计和插补合同、输入/输出哈希以及正确的 pooled likelihood 计算。存在编号 `.out` 但缺少精确 pair、观察协变量分布改变或只完成部分 pooling 时，保持 `sensitivity_only`/`defer_source_followup`/`defer_nested_pooling_audit`，不要填入 p 值。

## MI 与派生得分

10 份插补文件的列数、行数和字节对齐只能证明数据读回。收入定义、负值/缺失语义、确定性二分类、最终停止规则和链混合证据仍要独立审查；不能截零、取绝对值或无依据重编码。rank/score source 还需封闭 tie、availability、个人/夫妻身份和输入哈希，之后才物化消费者。

本机 Windows 只读入口：

- `work/pp_lgcm_reconciliation_20261001/audit_cfps_scientific_boundaries_20261004.py`；
- `reports/cfps_scientific_boundary_audit_20261004/cfps_scientific_boundary_audit_v1.{json,md}`。

该审计的 `new_mplus_submissions=0` 是成功的复盘策略：已有历史证据优先，只有真正缺少证据且资源门通过时才建立隔离新估计。

## 自由时间载荷与起点稳定性

2026-11-04 的 SONGAP 同 MI01 诊断提供了一个可复用的边界：保存点的
局部均值／协方差失配支持准备一个明确标注的形状敏感性；负方差本身不授权
按是否跑通或显著性反复改模型。原 E0 无数值积分，单纯加积分点没有针对性。

该敏感性仅将 Y 的三个中间时间载荷由固定改为自由，首末端点仍为 0/1，
样本、控制、MLR、自由 SY 和其余模型语法保持一致，参数从 130 增为 133。
原有合法的跨样本初始化值保留，未将失败 E0 的负方差终点当成合法起点。
随后另行固定一次不同起点检查：改变载荷、均值及回归初值，保留方差和
残差协方差初值，并核起始矩阵正定；未使用首次成功终点初始化。

两次均经 Windows RStudio/ClaudeR 异步 R → MplusAutomation 1.3 →
有界 Mplus 执行，分别耗时 20.446337 和 12.092091 秒。它们是两个独立
有限合同，不把第一次未用完的上限视为免费重试，不冲抵既有失败成本。
本例合计 32.538428 秒只代表这两个引擎调用，不代表端到端开发效率。
Windows 本机 agent 与 Mac 远程 agent 使用同一科学脚本和验收规则。

比较前，Windows 核数据字节 SHA，Mac 核绑定回执及聚合输出；并核实
2894 人／2134 户、全部 133 个参数语义、原输出 TECH1、完整 TECH3、
模型残差矩阵和正常退出。按语义对齐，不依赖
参数编号恰好相同。预先固定 LL 差≤.01、六条结构路径及三个形状载荷的
估计差≤max(.001,.01×参考 SE)、相对 SE 差≤5%；全部 133 个差异同时保留。
LL 若只打印三位小数，纳入两端舍入误差界，不能把打印相同当成精确相等。
本例预设九项和全部参数均通过，最大相对 SE 差为 2.5061%；两起点一致
仍不证明全局最优、跨 MI 稳定或完整推断。

数值合法性和测量解释须分别报告。本例 SY 残差约 .246，所有矩阵门槛通过，
但自由载荷点估计非单调，均值残差有改善也有恶化，SRMR 从 .023 变为 .025。
不能称其解决了所有测量失配、证明负方差成因，或将新 SY 继续解释为日历
线性变化率。载荷点估计的转折也不等于已检验出总体转折；原非法解与新解
的描述对照不能直接作普通嵌套似然比检验。

这种结果保留为端点锚定的事后敏感性，不回填原主模型或 H4 完成格。
基础模型两起点检查结束后，后续估计必须回答明确的研究目标；不能为了
增加成功数量自动铺开全部 MI。若继续原交互问题在新基底下的敏感性，先
冻结目标输入、低阶项、解释和有限预算，再独立验收；完整 MI 仍要求全部
预定成员有效和完整协方差合并。科学采用与替换主规格是另外的决策。

`STABILITY_SCIENTIFIC_REVIEW.json` 和 `DIAGNOSTIC_COMPARISON.csv`。
它们记录两组初值、全部参数差异、全部 5 个 Y 均值残差及 15 个 Y 协方差
残差，不以只展示改善项代替核验。
