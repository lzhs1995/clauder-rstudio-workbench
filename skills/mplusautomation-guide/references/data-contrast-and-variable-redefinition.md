# 数据对照真实性与同名变量重定义

适用于收入修正、敏感性分析、数据版本比较及旧结果复用。开始大队列前，
先证明干预确实进入模型消费的数据；不同路径或不同 SHA-256 不足以证明这一点。

## 有效对照的最小证据

1. 绑定两组原始 DAT 字节哈希、NAMES 顺序、样本/行键、缺失编码和行数。
2. 分层比较字节、逐行 token、精确数值。空白/换行差异会改变 SHA，但不改变模型。
   文本数字不同时，可用十进制精确数值比较；避免先转 double 丢失长 ID 精度。
3. 记录实际变化列、变化行数、缺失迁移及非目标列变化。期望改变的列全未变化时，
   将对照标为 `NO_DATA_INTERVENTION`，不要为证明“无影响”提交重复估计。
4. 检查变化变量是否被实际 USEVARIABLES/DEFINE/ON 或约束消费；只改未使用列仍非
   有效模型干预。固定样本对照另核对筛选、缺失删除、中心化、标准化和探查值。
5. 两组 INP 除声明的改动外应相同，并分别绑定 OUT 输入回显、N/簇数、终态、
   精度缓存的 OUT/RESULTS 哈希。技术绑定通过与科学对照有效须各有状态。

对于一行一个个案、纯数值、固定列数的空白分隔 DAT，可使用
`scripts/check_dat_intervention.py` 做流式只读预检。列名文件只含按顺序排列的
NAMES 名称；调用时显式指定行键、预期变化列和允许变化列。它不解析 Mplus
语法、不判断变量是否真正被使用，也不支持跨行个案/多组自由格式数据。
用 `--missing` 显式声明原模型的缺失 token（例如 Mplus 默认的 `.`）；
不推测 -999 是否为缺失。未声明的 NaN/Inf 或格式不符会拒绝，行键不可缺失。

若已完成错误对照，保留原输出、回执和旧报告，发布更正入口。可复用其
执行/解析测试证据；不能沿用“修正前后无差异”的科学解释。不要立即再估计：
先核查已有真正改变数据的诊断，保留其样本、规格和无 bootstrap 等适用边界。

## 同名字段必须追踪最后一次赋值

沿脚本追踪 `drop/rename/clonevar/replace` 与后续重新生成，而非在首次定义处停止。
记录每个阶段的测量对象、单位、组成项、特殊负值处理、存储类型和消费者。
在数据副本之外仅输出审计汇总，分层核对原问项→主 DTA→中间 DTA→CSV→DAT。

- Stata 原问项唯一前缀缩写可能指向实际带 `n` 后缀的列；按该版本真实列名解析，
  不猜列名。区分拒答、不适用、普通缺失和合法负值。
- `gen` 的 float 存储会在每次赋值舍入。多个加法分两次保存时，按相同阶段模拟
  float32 存储；不要把算术次序误差诊断成数据污染。
- 分析性“零转正”应检查新增组成项，不能直接归因为工资填补、CPI或缩尾。
- 家务日均值的等权平均与工作日/休息日 5∶2 加权是不同测量合同；两个原问项
  相同的记录无法区分算法，必须同时核验具有区别力的记录和适用问卷分支。
- 舍入 ID 的受约束唯一候选只能支持版本比较，不会因此恢复历史精确 ID 或
  证明遗失 CSV 的历史生成过程。

## 第四章案例与限制

2026-10-06/07 的只读回查中，当前 9748×2 个工资值与原问项相符；清理 do
2163–2174 行将工资、养老金和经营性分摊合成后改回 `child_income_`，随后重算
CPI/缩尾/log。72 组公式检查精确匹配，5175 个零工资转正合成收入由新增组成项解释。
当前 19496 个家务值符合 5∶2，历史 18056 个成员候选值符合等权平均。
这些证据不恢复 9028 原 CSV，也不自动证明历史全部收入列来自同一公式。

旧“全年度收入候选”三组 DAT（9121/3641/5480 行、146 列）的 token 全相同，
字节哈希不同；372 输入仅 FILE 路径不同，44902 精度行绑定通过。
35268 效应零差异应解释为同数据/同规格重复验证；基线合同已写明 repaired。
这是避免无效重复计算的直接经验，比新增 worker 或压低内存门槛更先应处理。

案例证据在 `ch4_source_correction_20261006/ROUND8_FINDINGS.md`、
`income_full_contrast_status.json`、`income_components_status.json` 和
`raw_wage_housework_status.json`；本地案例不是迁移到其他研究时的必需路径。

## 尾部算法的数值吻合与历史生成凭证

大量值吻合而少数尾部不同，先核对分位点计算样本、百分位单位、名义/平减
变量的比较条件、float储存和原始actor/partner方向。不要从观测最大值反推
一个阈值后宣称找到了历史代码；采用有独立源码/注释依据的假说，并保留
被数据拒绝的候选及未解释记录。恢复性审计中的假说比较不是选择更显著模型。

第九轮当前1%/99%规则仅解释17882/18056个历史工资候选；旧注释上限配合
历史方向解释18050；再按名义工资判断上端时18056全部吻合。随后3份旧do
确有0.1%/99.9%与名义工资比较的代码，但其输入是其他年份/面板合同。
因此可确认算法家族存在，不能认定它就是四期9028生产者，也未证明旧阈值
如何生成。值一致、算法家族相同、实际历史执行身份是不同证据层。

方法表述随数据版本审查：当前合成收入不能一律称工资，夫妻—时间数不能
称独立夫妻数，年份控制不能替代跨期相关的聚类/重抽样处理。隔离保存
原文—证据—候选表述—采用边界，避免只修改术语就把推断状态升级为通过。
案例候选在 `ch4_source_correction_20261006/manuscript_measurement_corrections.md`。

第十轮补充：分位点的计算样本还包括配偶方向。固定已匹配9028行方向后，
720行未知方向中只有3行可能影响上端分位点；穷举8种尾部组合，有2种均计算
出与旧注释一致的两个上限，并匹配18056个历史收入值。独立用排序统计量
的(n+1)p插值核验。上下界包含目标不等于离散组合可实现；应检查联合组合，
不能分别选择actor和partner的最佳界。多个兼容组合仍不证明唯一历史身份。
该核查只约束“固定当前工资、样本与CPI，仅改变未知方向”的假说空间，不能
外推旧版本其他变量或样本已相同。见 `ROUND10_FINDINGS.md`。
